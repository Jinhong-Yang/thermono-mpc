# AI assistance and human review

OpenAI Codex assisted with the initial package implementation, tests, evidence organization and manuscript draft. Generated suggestions and calculations are retained for human review; they are not an author or a substitute for experimental validation. The frozen control and prediction evaluations were run from recorded code, configuration, data and checkpoint hashes. No post-test tuning was used to change the reported v2 comparison.

Before public release or journal submission, the actual human authors must inspect the source, license rights, statistical interpretation, references, figures and paper text and approve the final version. The manuscript contains a separate generative-AI declaration draft consistent with the publisher's policy.
