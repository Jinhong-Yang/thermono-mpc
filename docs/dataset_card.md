# Synthetic dataset card

The frozen development dataset contains 24 train, six validation and six calibration trajectories. Each trajectory has 90 ten-second control intervals on a 16×16 grid. A whole trajectory belongs to exactly one split, so adjacent windows from one run cannot leak across train and validation. The generator varies density, heat capacity and conductivity between trajectories, creates bounded piecewise heater inputs and stores field/zone temperatures, heater powers and material multipliers. The manifest records file hashes and split identifiers.

The data are computer-generated by `scripts/generate_data.py` from `configs/frozen/protocol_v2.yaml`. Separate test trajectory seeds 9501–9508 and 12 control scenarios are held out. Test results were accessed only after the v2 freeze receipt and access log were recorded. A user should verify the archived data manifest SHA-256 against the release receipt before training.

Values are synthetic assumptions, not measured material properties or confidential industrial data. The model omits phase changes, temperature-dependent coefficients, 3D geometry, sensor calibration and actual equipment disturbances. Reuse on another furnace requires new process identification and validation. Do not label results from this dataset as industrial performance.
